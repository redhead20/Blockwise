# Blockwise

A rectangle-fill number puzzle. Drag to draw rectangles so that each one contains exactly one number and has an area equal to that number. Fill the whole grid.

- 70 levels, 4x4 up to 10x10 grids
- Numbers used: 1, 2, 3, 4, 5, 6, 7, 8, 10, 12
- Progress saved in the browser (localStorage)
- Single file, no build step, no dependencies

## Run it
Open `index.html` in a browser, or host it with GitHub Pages
(Settings -> Pages -> Deploy from branch -> `main` / root).
On iPhone: open the Pages URL in Safari -> Share -> Add to Home Screen.

## Files
- `index.html` - the game
- `manifest.webmanifest` - web app manifest (name, colors, icons)
- `icons/` - app icons (180 for iPhone, 192/512 for Android, a maskable 512, and a favicon)
